# QHYSICS

QHYSICS is a virtual-reality physics and education experience that lets anyone
with a VR headset explore electricity, circuit design, and the physical world
through hands-on experimentation.

## Circuit exploration

Beginners of all ages can connect wires, motors, bulbs, switches, and other
components to build arbitrarily complex circuits. Visualizing electron flow and
the effects on each component makes the behavior of real-world electricity
accessible, engaging, and intuitive.

## Physics playground

Beyond circuits, QHYSICS incorporates physics simulation, magnetic fields, and
tools for manipulating the virtual world. The project is designed to grow with
new experiments and interactive learning tools.

## AI tutor and guide

QHYSICS is planned to include an in-world AI tutor that can answer questions
using real-world knowledge, teach concepts, and interact with the environment.
The tutor will be able to manipulate the same virtual physics objects as a
user, acting as both a guide and a teacher during exploration.
